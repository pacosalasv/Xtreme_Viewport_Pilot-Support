## Overview

Xtreme Viewport Pilot is a browser testing extension. The supplied v1.7 manifest identifies Devices, Network/CPU, and Location as its core testing areas, with Chromium/Edge and Firefox builds.

## Product status

| Item | Details |
|---|---|
| Status | **Current build** |
| Version | 1.7 |
| Product type | Browser extension |
| Browsers | Chromium / Edge / Firefox |
| Distribution | Installable product files are not mirrored in this support repository. |
| Repository role | Documentation, support, issue tracking, compatibility feedback, and product feedback |

## Capabilities

| Capability |
|---|
| Device and viewport-oriented testing controls. |
| Network/CPU testing workflows. |
| Location-oriented testing workflows. |
| Uses browser debugging, scripting, storage, tabs, and declarative-network capabilities in the supplied manifest. |
| Chromium/Edge and Firefox builds in the supplied package. |
